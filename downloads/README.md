# Plex Goblin compact layout preview

[Download PlexGoblin-3.3.0-Compact-Preview.zip](https://github.com/xgoblinrogue88x/PlexGoblin/raw/refs/heads/main/downloads/PlexGoblin-3.3.0-Compact-Preview.zip)

Extract the complete ZIP into a fresh writable folder on Windows, then run `Start Plex Goblin.cmd`.

This preview adds a smaller responsive dark window, wrapping action bars, larger buttons and rows, compact Targets / Monitor / Activity views, and smaller settings dialogs for phone remote desktop sessions.

PowerShell syntax, unchanged playback logic, and clean packaging checks passed. Windows PowerShell 5.1 GUI, high-DPI, and S25 Ultra visual testing are still pending. This is a Windows desktop app used through your remote desktop client.

Keep an existing installation and its Data folder backed up. This ZIP contains no installed settings or credentials; Data/README.txt is its only Data file.
